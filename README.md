# Aegis Site

Landing page for Aegis, a Roblox Luau development group.

## Stack

- Plain HTML and CSS
- No frameworks, no build tools
- Served as static files

## Structure

```
index.html       main page
css/style.css    all styles
img/             images and icons
```

## Running locally

Open `index.html` directly in a browser. No server required.

## Images expected

| Path | Purpose |
|---|---|
| `img/logo.png` | Aegis logo, used in header and hero |
| `img/icon.png` | Favicon and site icon |
| `img/herobg.png` | Hero section background photo |
| `img/aegisvm.png` | AegisVM project card icon |
